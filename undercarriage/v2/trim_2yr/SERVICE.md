# V2 SERVICE — every 2 months (~85hr). 2-year / 1000hr design life.

Do all 12, tick off. ~45min with 2 people. Nylocks: replace any removed (5 reuses max).

1. Track sag 30-40mm at midspan; adjust via front screws, jam + paint-mark.
2. Torque audit all 28 flange M12s (80Nm) — paint marks must line up.
3. Idler/UCFL slot edges: look for crack starts (especially 5mm plates); dye-pen if suspect.
4. Shaft end-play: pull each collar — R-pins present, grubs tight + Loctite.
5. Disc wobble: spin rollers/idlers, watch belt runout (weld-toe check).
6. Chain stretch + guard bolts; spare link set in toolbox?
7. Beam bow sight-check along SHS32 midspan (straightedge).
8. UCFL grease nipples; 6205 listen/feel (heat = replace at next stop).
9. Blow out mud from loop, pockets, tensioner threads; grease adjuster screws.
10. Motor temp stickers read (max 90°C); battery gauge calibration ride.
11. Deck mounts + lift lugs: crack look at weld toes.
12. Log hours + what moved. If anything moved twice in a row -> escalate (that joint gets Nordlocks or a design change, not a third re-torque).
